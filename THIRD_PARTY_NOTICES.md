# Third-party sources and distribution

- **UMR**, https://github.com/hanyang9/UMR, commit `d1cdaedaf67a827198da71c5fa831f48b2e51f91`: MIT. License retained at `motion_retargeting/umr/upstream/LICENSE`. This distribution retains its adapted solver source and required `assets/smplx_parts_segm.pkl` face-part annotation, omits motion samples and unrelated robot assets, and records the included subset in `VENDOR_MANIFEST.json`. The original local adaptation is recorded in `upstream_adaptation.patch`. The annotation is not a parametric SMPL-X body-model file.
- **hiphi2smplx**, https://github.com/noitom-robotics/hiphi2smplx, commit `65e51315ebbc82b2f0ff8e35a94565beb1b345e1`: MIT. License retained at `motion_retargeting/umr/hiphi2smplx/LICENSE`. Documentation images and optional external beta-fitting resources are not included.
- **Deep Robotics model**, https://github.com/DeepRoboticsLab/deep_robotics_model: BSD-3-Clause. Source revision and original source inventory are retained at `mujoco/dr02_pro/SOURCE.json`; this release contains only `DR02/mjcf/pro/` and its required meshes, not the complete source inventory. License retained at `mujoco/dr02_pro/upstream/LICENSE.txt`.
- **SMPL / SMPL-X** model files are not distributed. Users must obtain the appropriate model separately under its applicable terms. The `smplx` Python package is an installed dependency; installing it does not provide the body model.
- **HiPHI** recordings, metadata records and derived captured body sequences are not distributed. Users obtain their own inputs from https://huggingface.co/datasets/noitomrobotics/HiPHI and follow the dataset terms. This repository's synthetic arrays do not contain captured motion or fitted actor shape.
- `examples/synthetic/` contains only programmatically constructed numerical signals and an independent FK playback, generated by `examples/make_example.py`. They are not UMR benchmark results.

Local wrappers derive from the same workspace's DR02 adaptation and have been made independent of its private datasets and deployment paths. Public changes add the portable CLI, model discovery, user-input conversion, CPU/CUDA surface-device selection, generic trajectory validation, examples and documentation. Upstream solver source is not modified by these public packaging changes.

The top-level MIT license covers this project's code; third-party files retain their own notices and terms. Data/model use rights are not granted by the code license.
